# Nuvora — Furniture E-commerce Website

Nuvora is a modern, responsive furniture e-commerce website designed with a clean, premium aesthetic. The project focuses on creating a polished shopping experience with responsive layouts, product browsing, filtering, sorting, and essential e-commerce pages.

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Modern and premium furniture-focused UI
* Product filtering and sorting
* Product pagination
* Product details page
* Collections and new arrivals
* Wishlist interface
* Shopping cart interface
* Checkout page
* Login page
* Contact page
* Responsive navigation and reusable UI components
* Clean and organized HTML, CSS, and JavaScript

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Font Awesome
* Google Fonts

## 📄 Pages

* Home

## 🚀 Getting Started

No installation or build process is required.

1. Clone this repository:

```bash
git clone https://github.com/mariam-webdev26/nuvora-furniture-website.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it.

## 🎯 Project Purpose

This project was created as a frontend e-commerce project to practice and demonstrate responsive web design, UI development, product layouts, navigation, and JavaScript-based interactions.

## ⚠️ Note

Nuvora is currently a frontend project. Authentication, real payment processing, database integration, and backend order management are not implemented.
